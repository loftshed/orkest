# Orkest Architecture & Module Map

Orkest is a cross-harness multi-agent orchestrator and spare-token software factory across Claude Code, Codex, Antigravity (Gemini), and OpenCode.

## 1. Command & Subsystem Glossary (Orc Stronghold Vocabulary)

Every Orkest command has a plain-English engineering meaning alongside its `ork` name:

| Command           | Module                                                                                                                                                                                    | Plain-English Engineering Role                                                                                                                                                                                                                                                                                                                                                    |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`ork horde`**   | [`lib/horde-view.mjs`](../plugins/orchestrate/lib/horde-view.mjs)<br>[`bin/ork.mjs`](../plugins/orchestrate/bin/ork.mjs)                                                                  | **Live Multi-Agent TUI & Pack Spawner**: Opens or toggles the live terminal split-pane card tree showing all active agents grouped by folder and disposable worktree (`wt:<slug>`), with a compact subscription quota strip.                                                                                                                                                      |
| **`ork hall`**    | [`lib/hall.mjs`](../plugins/orchestrate/lib/hall.mjs)<br>[`lib/rooms.mjs`](../plugins/orchestrate/lib/rooms.mjs)<br>[`lib/stooges-room.mjs`](../plugins/orchestrate/lib/stooges-room.mjs) | **Shared Coordination Room Store**: Creates, binds, observes, and updates multi-agent coordination rooms, leadership branches, and disposable worktree retention (`ork hall worktree-keep`).                                                                                                                                                                                      |
| **`ork foundry`** | [`lib/foundry.mjs`](../plugins/orchestrate/lib/foundry.mjs)<br>[`lib/factory.mjs`](../plugins/orchestrate/lib/factory.mjs)                                                                | **Spare-Token Issue Harvester & Worktree Dispatcher**: Monitors expiring flat-rate subscription windows (`monitor`), matches open GitHub issues (`Depends on #N` DAG-aware) to surplus model pools, provisions disposable git worktrees (`.worktreeinclude`), and dispatches bounded worker runs.                                                                                 |
| **`ork smelter`** | [`lib/smelter.mjs`](../plugins/orchestrate/lib/smelter.mjs)                                                                                                                               | **Automated Worktree Verification, Cold-Review & Merge Queue**: Takes completed disposable worktrees (`wt-<issue>`), rebases onto the target branch, classifies blast-radius risk tier (`low`/`medium`/`high`), runs the serialized heavy test gate (`ork gate --heavy`), dispatches a cross-vendor cold code review (`consult --intent review`), and merges/prunes the worktree. |
| **`ork radar`**   | [`lib/radar.mjs`](../plugins/orchestrate/lib/radar.mjs)<br>[`scripts/telemetry.py`](../plugins/orchestrate/skills/orchestrate/scripts/telemetry.py)                                       | **Model Release Radar, Benchmark Priors & Silent-Nerf Detector**: Compares live harness catalogs against `models-seen.json` and external scoreboard priors (`benchmarks.prior.json`), and flags `DEGRADED` models when their 14-day rolling Wilson pass rate drops $\ge 15\%$ below baseline.                                                                                     |
| **`ork gate`**    | [`scripts/gate.py`](../plugins/orchestrate/skills/orchestrate/scripts/gate.py)                                                                                                            | **Serialized Heavy Verification Lock**: Coordinates exclusive execution of CPU/memory-intensive test suites, builds, and project-wide linters (`ork gate --heavy -- <cmd>`) across concurrent agents sharing the machine.                                                                                                                                                         |

## 3. IDE & IntelliSense Setup

- **JavaScript / `.mjs`**: Configured via root [`jsconfig.json`](../jsconfig.json) (`NodeNext` module resolution). Exported functions across `plugins/orchestrate/lib/*.mjs` include JSDoc `@param` and `@returns` annotations for VS Code / Cursor / Antigravity hover tooltips.
- **Python / `.py`**: Configured via root [`pyrightconfig.json`](../pyrightconfig.json) (`extraPaths` pointing to `plugins/orchestrate/skills/orchestrate/scripts` and `tests/plugins/orchestrate/skills/orchestrate`) so Pylance/Pyright resolves sibling script imports and renders PEP 257 docstrings and type annotations on hover.
