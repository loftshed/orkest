# Orkest Architecture & Module Map

Orkest is a cross-harness multi-agent orchestrator and spare-token software factory across Claude Code, Codex, Antigravity (Gemini), and OpenCode.

## 3. Core Runtime Contracts

### A. Lease-Backed Workboard (`leaseExpiresAt` & `handoff` Packets)

- **TTL Leases & Heartbeat Renewal**: Claiming a workboard item sets a `leaseExpiresAt` timestamp (default 15-minute TTL), renewed on `ork progress` heartbeats (`agent_progress.py`) and `checkpoint` mutations. Expired or owner-absent items remain in `claimed`/`blocked` with `leaseExpired: true` and `recoveryNeeded: "lease_expired"` (or `"owner_absent"`), can be atomically taken over via `claim` / `reclaim` (or returned to `open` via `recover`), and bump `revision` on takeover so stale writes fail compare-and-swap with `"work revision conflict: current revision ..."` (`stale_revision`).
- **Structured `handoff` Packets**: `checkpoint`, `release`, and `submit` accept a structured `handoff` object (`files_touched`, `decisions_made`, `remaining_steps`, `blockers`, `verification_command_run`) so a successor agent or reviewer can resume without re-discovering context.

### B. Scoped Verification Gates (`--verify`, `--acceptance`, `foundry-state.json`)

- **Foundry Evaluation Contracts**: `ork foundry` (configured and tracked via `foundry-state.json`) and task specs support scoped `--verify` (`verify_cmd`) and `--acceptance` (`acceptance_criteria`) flags.
- **Post-Builder Verification**: Builders run scoped verification commands (capped at `--maxWorkers=2`) outside the model after handoff, paired with acceptance criteria checks before a worktree advances to `ork smelter`.

### C. Deep Herdr Integration (`herdr pane report-metadata`, `.herdr/commands.toml`)

- **Live Pane Metadata & Notifications**: When `HERDR_ENV=1`, `agent_terminal.py` and `agent_progress.py` push display-only pane titles, agent badges, and state labels via `herdr pane report-metadata` (debounced on change) and emit attention notifications when workers block, fail, or complete.
- **Interactive Pane Focus & Command Palette**: Pressing `o` in `HordeView` focuses the selected agent's Herdr or tmux pane. Repository-level commands and shortcuts (`orkest.toggle-horde-view`, `orkest.quota-radar`, `orkest.smelter-audit`, `orkest.foundry-status`) are declared in [`.herdr/commands.toml`](../.herdr/commands.toml).

## 4. IDE & IntelliSense Setup

- **JavaScript / `.mjs`**: Configured via root [`jsconfig.json`](../jsconfig.json) (`NodeNext` module resolution). Exported functions across `plugins/orchestrate/lib/*.mjs` include JSDoc `@param` and `@returns` annotations for VS Code / Cursor / Antigravity hover tooltips.
- **Python / `.py`**: Configured via root [`pyrightconfig.json`](../pyrightconfig.json) (`extraPaths` pointing to `plugins/orchestrate/skills/orchestrate/scripts` and `tests/plugins/orchestrate/skills/orchestrate`) so Pylance/Pyright resolves sibling script imports and renders PEP 257 docstrings and type annotations on hover.
